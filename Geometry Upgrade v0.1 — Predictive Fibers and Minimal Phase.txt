2. From present fibers to predictive fibers
Fix a set X and a total deterministic update U: X → X. Thus X is forward invariant. Fix a surjection π: X → Q and a witness W: X → Y. Put B(x) = (π(x), W(x)), taking only the actual image as its codomain. B is the parent’s present-time witness-resolving observation.
Πₕ(x) = (B(x), B(Ux), …, B(Uʰx)),  h ≥ 0.
x ≡∞ y  ⇔  B(Uᵏx) = B(Uᵏy) for every integer k ≥ 0.
Π∞(x) = (B(Uᵏx))ₖ≥₀;    Q∞ = Π∞(X).
Theorem — Coarsest predictive refinement. The left shift maps Q∞ to itself and defines an autonomous update U∞ satisfying U∞ ∘ Π∞ = Π∞ ∘ U. The first coordinate recovers B, hence π and W.
Moreover, suppose p: X → Z is surjective, B = b ∘ p, and p ∘ U = V ∘ p for a deterministic V: Z → Z. There is a unique H: Z → Q∞ with Π∞ = H ∘ p. Explicitly, H(z) = (b(Vᵏz))ₖ≥₀. Therefore any exact autonomous description retaining B must distinguish every pair distinguished by Π∞.
Proof. Shifting Π∞(x) gives Π∞(Ux), so the shift remains in the actual image. The identity p(Uᵏx) = Vᵏp(x) follows by induction, giving the displayed H and factorization. Surjectivity of p gives uniqueness. Thus Q∞ is coarsest in the factorization order. This is a claim about retained information, not a claim of smallest dimension, fewest bytes, or mechanistic minimality.
This future sequence characterizes the required equivalence; it is not an instruction to use future outcomes as predictor inputs. A usable implementation needs an available present-state coordinate that realizes the factor. The phase construction below supplies one for the declared formal model.
The horizon-h obstruction is a non-descent locus in the parent’s precise sense:
Nₕ = {q ∈ Πₕ(X): ∃x,y, Πₕ(x) = Πₕ(y) = q,
                         B(Uʰ⁺¹x) ≠ B(Uʰ⁺¹y)}.
Its points contain states agreeing through horizon h that split at the next step. No topology, connectedness, boundary, or holonomy follows from this set definition alone.


2.1 Exact predictive closure and robustness are different properties


A closed retained update can be unstable to perturbation even when every fiber has a well-defined successor. In the static gear comparator x*(t)=−cuberoot(t/80), retaining t determines a unique contact minimum, but there is no finite Lipschitz bound at zero. This is a conditioning example, not a counterexample to the finite exact compiler.


For a deterministic reduced map F that is L-Lipschitz on a declared forward-invariant metric domain, suppose an approximate map F̂ has uniform one-step error d(F̂(z),F(z))≤ε and both trajectories stay in that domain. Then e_(n+1)≤L e_n+ε. Induction gives e_h≤L^h e_0+ε∑_(j=0)^(h−1)L^j: for L=1, e_h≤e_0+hε; for 0≤L<1 the accumulated term is at most ε/(1−L). These premises are additional to exact set-level closure. A fitted trace supplies neither a global L nor a uniform ε.


Retain the declared clock. Reparametrizing a path can preserve its image while changing sampled successors, speeds and event frequencies. The existing 39-screen boundary conventions, minimality results and finite-horizon law statements retain their own domains.

3. A finite compiler with an exact stopping rule
Let Eₕ = Eq(Πₕ). The refinement recurrence is
Eₕ₊₁ = Eₕ ∩ (U × U)⁻¹(Eₕ).
If Eₕ₊₁ = Eₕ on the entire declared domain, Eₕ is forward invariant and equals ≡∞. Equivalently, Nₕ is empty. The update on Πₕ(X) is then well defined. Equality here is equality of partitions, not necessarily equality of their arbitrarily chosen labels.
For a complete finite domain with N states and k₀ initial B-classes, every strict refinement increases the number of classes. There are at most N − k₀ strict refinements. Split a class whenever its members have successors in different current classes; repeat until stable. This is the deterministic partition-refinement construction familiar from automata minimization, specialized to the project’s typed observations [A1].
Worked model: X = {0,1,2,3}, U(0)=1, U(1)=2, U(2)=3, U(3)=3; B(0)=B(1)=B(2)=0 and B(3)=1.
h = 0:  {0,1,2} | {3}
h = 1:  {0,1} | {2} | {3}
h = 2:  {0} | {1} | {2} | {3}  — stable.
States 0 and 1 agree now and one step ahead but differ two steps ahead. A current-only or one-step check misses that distinction. Conversely, the four-cycle U(i)=i+1 mod 4 with B(i)=i mod 2 closes immediately on two classes; the compiler does not always force the full source state.
A partial trajectory is not a complete transition table. Missing successors, unknown observations, unsupported matching, or uncovered representatives cannot earn closure. Never manufacture a terminal self-loop to make an observed record look complete. The included implementation rejects a domain whose update leaves the supplied state set.
4. The 39-screen closes on a smaller phase factor
Use the parent’s exact fixed rotation on the circle T = ℝ/ℤ, with representatives θ ∈ [0,1). Braces denote fractional part. This section derives an ambient-circle factor and then restricts it to the parent’s golden trace θₙ = {nα}.
α = (3 − √5)/2;    θₙ₊₁ = {θₙ + α}.
bₙ = ⌊39θₙ⌋;    jₙ = (bₙ₊₁ − bₙ) mod 39 ∈ {14,15};
sₙ = bₙ mod 3;    σₙ = 15 − jₙ ∈ {0,1}.
Define β = 39α − 14, τ = 1 − β = 15 − 39α, and γ = {13α}. All three are irrational; β and τ lie strictly between 0 and 1.
ρₙ = {39θₙ};    ρₙ₊₁ = {ρₙ + β};    σₙ = 1[0,τ)(ρₙ).
Proof. Write 39θₙ = bₙ + ρₙ. Before reduction modulo 39, the next bin increment is 14 + ⌊ρₙ + β⌋. Therefore σₙ = 1 − ⌊ρₙ + β⌋, with the half-open boundary exactly as displayed. Slip alone has the exact autonomous driver ρ.
For the joint strand/slip observation define
zₙ = {13θₙ};    zₙ₊₁ = {zₙ + γ};
sₙ = ⌊3zₙ⌋;    ρₙ = {3zₙ};    σₙ = 1[0,τ)({3zₙ}).
Proof. Write 13θₙ = k + zₙ for an integer k. Then 39θₙ = 3k + 3zₙ, so reduction of its floor modulo 3 gives ⌊3zₙ⌋, and its fractional part is {3zₙ}. The update follows from taking fractional parts of 13(θₙ + α). Thus one phase z determines both observations and all their future values.
The existing current-pair failure is preserved: at n=1 and n=8, (sₙ,σₙ)=(2,0), but σₙ₊₁ is respectively 0 and 1. Those two times have different z. Adding the sufficient driver changes the state being tested; it does not overturn failure of the smaller current-pair law.
5. Minimality is relative to the observation
The phase factors above are coarsest for their stated output obligations on the full circle.
For the strand/slip pair, equal z gives identical future observations by the displayed update. If z′≠z, let d=z′−z mod 1. The labeled partition into the three intervals [0,1/3), [1/3,2/3), [2/3,1) is not invariant under any nonzero translation. Consequently there is a nonempty open interval on which ⌊3u⌋ and ⌊3(u+d)⌋ differ. Because γ is irrational, the forward orbit of z is dense and eventually enters that interval. The two future strand sequences then differ. Future-pair equivalence is therefore exactly equality of z.
The same argument proves slip-only minimality for ρ: the proper interval [0,τ) has no nonzero translation symmetry, and rotation by irrational β is dense. Two distinct ρ values eventually give different slip labels. Irrational-rotation coding is standard symbolic dynamics; the screen-specific factors and proofs here are applications to the retained definitions [A2].
On the full source circle, θ ↦ {13θ} has exactly 13 preimages for each z. This is a 13-sheet quotient, not a 13-state model or a 13-fold reduction in dimension. Both spaces are circles. Restricted to the single golden forward orbit, the map is injective: equality would require 13(n−m)α to be an integer. Thus it does not merge two distinct indexed trace points.
If the full bin label b must remain available, z is insufficient: its 13 lifts have bin labels s, s+3, …, s+36. Future bin observations distinguish the full phase θ by the same density argument. Likewise, none of these reductions promises to preserve additional clock, origin, reset, provenance, or coupling observations. Each added observation can refine the minimal factor.
6. No fixed finite history can close the exact slip sequence
Theorem — All-time finite-state obstruction. For every initial phase of the declared irrational rotation, no deterministic autonomous finite-state system with a fixed slip readout generates the exact infinite slip sequence.
Proof. From ρₙ₊₁ = ρₙ + β − ⌊ρₙ + β⌋ and σₙ = 1 − ⌊ρₙ + β⌋,
σₙ = τ + ρₙ₊₁ − ρₙ;
σ₀ + ⋯ + σ_{N−1} = Nτ + ρ_N − ρ₀.
Writing ρ_N for the phase at step N, Since ρ remains in [0,1), the frequency of slips converges to τ = (39√5 − 87)/2 ≈ 0.103325561245899, an irrational number. Every trajectory of a deterministic map on a finite set is eventually periodic. Its binary output has a rational limiting frequency. This contradiction proves the theorem.
A stationary rule using any fixed m past slip bits has at most 2ᵐ histories and induces a finite deterministic shift-register update. It is therefore ruled out. A fixed-length history of the finite strand/slip alphabet is ruled out for the same reason. The theorem strengthens the parent’s first-order counterexample without changing that result.
This leaves room for exact infinite-state phase descriptions, unbounded counters, explicit external inputs, nonautonomous rules, finite-horizon fits, and approximate or probabilistic models. Their success requires their own declared task and validation. The theorem concerns exact deterministic autonomous generation for unbounded time.
7. Executed verification and empirical use
The accompanying Python program uses integer arithmetic in ℚ(√5) and exact integer-square-root floor evaluation. No floating-point value decides a bin, slip, boundary, or equality. It passed 10,001 source-phase checks, 78 exact bin/threshold boundary checks, and 4,160 future comparisons across the 13 lifts of selected reduced phases. The n=1/n=8 parent counterexample was reproduced.
For 10,000 departures the program found 1,034 slips and verified the exact telescoping identity. It located equal-history/different-successor pairs for history lengths 1, 2, 4, 8, 16, 32, and 64. The finite compiler produced class counts 2→3→4 for the delayed-split model and retained two classes for the compressible four-cycle. An incomplete transition domain was rejected.
These computations check the implementation and finite examples. The all-time obstruction and factor minimality rest on the written proofs; a finite prefix alone would not establish either. The package contains the executable program, its actual result JSON, and this companion text. It uses only the Python standard library.
For empirical use, fix the observation B, update/input conditions, prediction horizon, same-fiber rule, eligibility, uncertainty, and coverage before scoring. Keep present observations distinct from future labels. A located same-observation/different-future pair defeats the proposed exact state description; absence of a pair in sparse data does not certify it.
The frozen LBCO gate remains a detection-only result for one located fiber. Chemistry freeze, global non-descent shape, connectivity, boundaries, transport, holonomy, and universal empirical predictive closure receive no upgrade here. The null 72-model bank result remains null, and platform instantiation remains unresolved.
