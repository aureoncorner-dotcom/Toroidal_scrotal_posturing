## Integrity and review limits

* Upgrade checksum receipt: 17/17 files matched.
* Corner Relay archive: 10/10 members matched the corresponding loose files.
* Corner Relay execution receipt: 9/9 listed file hashes and its saved test-output hash matched.
* Reference trace: reproduced object and canonical trace hash matched exactly.
* Earlier audit manifest: 17/17 packet hashes and both listed audit-output hashes matched.
* Word structure: 16 tables, six embedded images, no tracked insertions/deletions or comments part; embedded poster matches the loose poster. Page layout was not certified because the bundled renderer is unavailable.
* Current supplied software suite: 20 tests passed. The separate review verification completed 36 checks, including deliberate reproductions of mathematical and code counterexamples.
* The separate TOROIDAL_v013_ORBIT_COCYCLE_UPGRADE_PACKET_2026-09-02.zip is 22 bytes and contains zero entries. It supplies no additional version to compare.

No lattice-field implementation, executed Q2 validation artifacts, raw rotating-lattice dataset, or the Word synthesis's source case-level datasets were present. The comparison therefore evaluates supplied mathematical statements, specification coherence, reported arithmetic, local integrity, and the actual reference code. It does not independently reproduce the reported platform experiments or produce a new field-simulation result.
