# GQG relation typing v0.3

Every cross-model connection needs a relation type and a scoped payload. Shared geometric words do not supply a map between models.

| Relation | Required support | Example in this release |
|---|---|---|
| DERIVED_DESCENT | Explicit map, update, domain and factor/closure proof | A proven quotient law on its declared domain |
| CONSTRUCTOR_CHOICE | Stated model assumption and parameters | Choosing a periodic cubical field or circular tube |
| MOTIVATED_BY | Motivation stated without inferred equivalence | Using a geometric pattern to propose a comparator |
| CALIBRATED_AGAINST | Defined measurement/calibration and compatible quantities | A future axial convention check |
| COMPARED_WITH | Separate models, common declared observable | Empirical field profile against the throat construction |
| ORBIT_ACCESSIBILITY | Enabled full-state paths and starting domain | Explicit finite graph or proven operator paths |
| COCYCLE_IDENTITY | Base path/address and group-valued increment | q endpoint difference or fixed-radius flux difference |
| FORBIDDEN_TRANSPORT | Named missing implication | Phase-screen arithmetic offered as Q2 evidence |

These successor types consolidate the older orbit additions; they do not rewrite the preserved original vocabulary. An exact spatial flux cocycle is a conservation identity. It does not imply a temporal law for a reduced observable. Static gauge invariance also does not imply strong lumpability.

The phase-screen model, toroidal gauge constructor, circular fluid-like kinematics, diagonal routing chart, silver/Pell arithmetic and timestamp-driven lattice remain distinct objects. Rectangular homology transfers through an explicit geometric derivation; a microscopic coupling or measured outcome does not transfer along that same relation.

A relation record should contain source model/version, target model/version, relation type, explicit map or comparator, hypotheses, scope, supporting artifact and status. Missing hypotheses remain missing. `DERIVED_DESCENT` requires a proof or complete finite-domain argument; an empirical agreement is only a scoped comparison.
