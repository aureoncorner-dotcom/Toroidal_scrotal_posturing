# Mathematical audit of the TOROIDAL v0.13 orbit/cocycle packet

**Audit date:** 2026-09-02  
**Archive:** `TOROIDAL_v013_ORBIT_COCYCLE_UPGRADE_PACKET_2026-09-02.zip`  
**Archive SHA-256:** `c9d7177e1f0c6527eaf928195f98af25a9b00f062bcc848a02738029d007d8f3`  
**Disposition:** **ADOPT WITH MAJOR MODIFICATION / do not treat the current packet as an executable frozen specification.**

## Bottom line

The central finite-group algebra is good:

- the fixed-reference character expansion and Walsh–Hadamard transform;
- (Z_{\rm full}=\mathcal Z_{000});
- (q=W\bmod 2) on the divergence-free (h_6=0) Q2 domain;
- (f_{\rm odd}^{(\alpha)}=\tfrac12(1-Z_{e_\alpha}/Z_{000}));
- the telescoping sector and flux cocycles; and
- the unlabelled (q)-site period (T_g/q), under the stated equally spaced, identical-site symmetry.

However, the packet contains several genuine mathematical errors, a potentially biased Markov-chain stopping rule, an internally inconsistent Q2 scale/deconfinement branch, and enough damaged equations that parts of the frozen text are not literally auditable. The rotating-lattice numerical report is internally conservative, but its reported AUCs, (p)-values, and intervals cannot be independently recomputed from this archive.

## Highest-priority findings

### 1. The odd-(L) diamond sheet bit is not well-defined — high

**Locations:** `01_Field_Theory_Update...md:1447-1455`; `05_TTSC...md:305-313`.

The packet defines

\[
c(x,y)=(x+y)\bmod 2
\]

on ((\mathbb Z/L\mathbb Z)^2) and then discusses both even and odd (L). Reduction modulo 2 descends from (mathbb Z/L\mathbb Z) only when (L) is even. For (L=3), the allowed diagonal move

\[
(2,0)\longrightarrow(0,1)
\]

changes representative parity from (0) to (1). Thus (c) is not a function on the odd-(L) torus.

The component count is correct: the subgroup generated by (e_+=(1,1)) and (e_-=(1,-1)) has index (gcd(2,L)), giving two components for even (L) and one for odd (L). The repair is:

- for even (L), retain the (C_2) sheet invariant;
- for odd (L), state that the graph is connected and no nontrivial sheet bit exists.

This is also a source-to-application error: the companion weave example uses even cyclic factors, where the parity map is well-defined; it cannot be generalized unchanged to arbitrary odd (L).

### 2. The worm macro-sweep is not yet a proved target-preserving kernel — high

**Locations:** `02_Simulation_Protocol...md:1328-1330,1382`; `03_Appendix_A...md:278-280,330-332,373-377`.

Local link Metropolis ratios do not fully specify a worm kernel. The text omits the extended-ensemble defect weights, insertion/removal and closure probabilities, rejection behavior, and full transition probability.

More importantly, worms are repeated until a **state-dependent random cumulative accepted path length** first exceeds (3L^3). Even if each completed worm kernel preserves the target distribution, stopping a sequence at a path-length-dependent hitting time need not preserve it. This requires a proof for the complete macro-kernel or an exhaustive finite-state transition check. A safer alternative is a frozen number of fully specified target-preserving worm kernels.

Until repaired, the detailed-balance/reachability gate cannot validate the production kernel.

### 3. There is no single operative Q2 scale/deconfinement rule — high

**Locations:** `02:883-903,920-922,1388,1476`; `04:1657-1673,2468-2481`; `14:3-5,11-14,20-28,83-115`.

The packet contains three incompatible versions:

1. the earlier protocol uses (L_{\max}\ge4\xi_{\rm conf}), with malformed `4,\xi` at `02:887,896`;
2. later text uses the 95% upper confidence bound (L_{\max}\ge4\xi_{\rm conf}^{95\%,\rm UCB});
3. file 14 correctly says the inequality is inapplicable when a long-range model is preferred, but file 14 is explicitly proposed/noncanonical and has no scoring effect.

Appendix B makes the conflict sharper: its deconfinement branch requires both the finite-(\xi) size gate to pass (`04:2473`) and the long-range model to be preferred (`04:2479`). Under file 14's correct interpretation, long-range preference means no finite confinement radius has been established and the (4\xi) gate is inapplicable. As written, the deconfinement branch is either impossible or depends on an undefined use of (\xi_{\rm conf}).

Adopt one canonical branch table and regenerate every dependent status, schema, and hash. The recommended rule is the file-14 structure, with an explicit long-range verdict path that does not pretend a finite confinement radius was estimated.

### 4. The three (h) labels are fixed-reference Wilson-loop sectors, not path-independent global holonomy sectors — high/medium

**Locations:** `01:410-463`; `03:48-76`.

With fluctuating plaquette curvature, homologous Wilson loops need not agree. For two parallel representatives separated by a strip (S),

\[
H(\Gamma')H(\Gamma)=\prod_{p\in S}B_p.
\]

Therefore the three frozen loop signs define a valid, gauge-invariant eight-way conditioning and the character transform remains exact, but they are not path-independent topological holonomy classes unless flatness or a deformation-invariance condition is imposed.

Use “fixed-reference Wilson-loop sectors” (or explicitly defined boundary-twist sectors). Do not infer a global topological gauge-holonomy sector from one chosen representative when plaquette flux fluctuates.

### 5. (W_\alpha=L^{-1}\sum I_\ell\) need not be integer at finite (h_6) — high/medium

**Locations:** `01:266-329,1358-1384`; `02:228-234,356-370`; `03:146,184-202,358-363,465-493`.

Integer winding follows from integer **divergence-free** current. At finite (h_6), the constraint permits charge-six endpoints,

\[
\nabla\!\cdot I=-6n.
\]

For example, on (L=4), current (6) on one (x)-link with compensating (n=\pm1) endpoints is admissible but gives (W_x=6/4=3/2). Hence (W\bmod2) is not defined as an integer parity observable on that broader domain.

Canonical Q2 is saved by its (h_6=0) scope. Every use of integer (W), (q=W\bmod2), and the signed-winding tape must repeat that scope. At finite (h_6), define parity through the cut pairing of (I\bmod2), not through (W\bmod2).

### 6. Important equations are damaged in the hashed packet — high

**Locations:** `01:1117-1134,1143-1248`; `02:102-110,151-155,172-193,358-389,887,896,924`; `04:124-154,630-681,1685-1703`, with similar damage throughout its inherited base section.

Examples include missing equality signs, missing operands, bare `[`/`]` in place of display-math delimiters, a truncated decision-table row, and replacement/private-use glyphs. File 01 contains seven Unicode replacement characters; file 04 contains 312 private-use characters. Some intended formulas can be reconstructed from context, but a frozen executable specification cannot depend on reconstruction by the reader.

Regenerate the Markdown from a clean source, render it, compare every equation to the source, and only then issue new hashes. The current hashes faithfully bind the damaged bytes; they do not repair them.

### 7. The rotating-lattice statistics are not independently reproducible from this archive — high for empirical verification

**Locations:** `06:10,30-37`; `07:4-9`.

The archive omits the hashed source CSV, `rotating_lattice_results.json`, analysis code, candidate ledger, permutation/bootstrap counts, random seeds, tie convention, and frozen analysis plan. Therefore the reported AUCs, familywise (p)-values, and confidence intervals cannot be recalculated here.

The summary arithmetic is consistent, and the null verdict follows from the reported numbers: the best exact candidate misses the AUC, familywise-significance, call-direction, and concentration gates. That checks the **logic of the stated verdict**, not the underlying computations.

### 8. (p\ge0.05) is incorrectly used as evidence of agreement — high/medium

**Locations:** `03:388-400` and the duplicate protocol text near `02:1440-1441`.

A nonsignificant difference test can pass merely because it has low power. It does not establish axis symmetry, placement agreement, or convergence. Replace these gates with preregistered equivalence margins and simultaneous confidence intervals or a formal equivalence test, including the intended multiplicity handling.

The “within three combined standard errors” comparison and the consecutive-(L_{\min}) stability statistic also need covariance from paired/bootstrap replicates because the compared estimates use overlapping, highly correlated data.

## Additional findings

### 9. Strong lumpability is overstated

**Locations:** `01:1429-1445`; `02:1623-1646`; `03:565-596`.

Strong lumpability is necessary and sufficient for the projected chain to be Markov for **every** initial full-state distribution. Weak lumpability can suffice for a specified stationary law. Rename failure as `STRONG_LUMPABILITY_FAILED`, or define “q-only closure” explicitly as a universal projection property.

For empirical nonclosure, different single realized next states are not a counterexample in a stochastic system. The required witness is a difference in aggregate next-sector probabilities for same-(q) full states, as `03:591-592` correctly says.

### 10. Formal orbit span requires liftability through the full state graph

**Locations:** `01:1334-1355`; `02:1584-1599`; `03:534-549`.

\[
\mathcal O(q_0;S)=q_0+\operatorname{span}_{\mathbb Z_2}S
\]

is exact for a genuine quotient translation action. If proposal availability, nonzero acceptance, or a current cutoff depends on hidden full-state coordinates, observing each generator somewhere does not prove their lifts can be composed from every starting state. Define formal reachability using enabled generators with proved feasible lifts, or compute positive-probability paths on the full-state graph.

Also replace “no accepted sector moves” with “no enabled sector generators” when describing formal rather than observed reachability.

### 11. The TTSC throat is exact only in a straight/slender cylindrical chart

**Locations:** `05:59-99,101-162,259-289,357-365`.

The field

\[
v_s=U(s),\qquad v_r=-\frac r2U'(s)
\]

is exactly divergence-free in a straight axisymmetric cylinder. Writing the general metric-divergence formula does not itself supply toroidal-curvature corrections. The later radius, tangency, and side-flux formulas therefore remain straight-chart formulas unless a controlled slender-tube approximation is stated.

The sign claims also require (U_0>0), positive radii, and a specified lifted half-period monotone window. “Before/after (s_0)” is not globally monotone on a periodic circle.

### 12. The two-clock JSON is valid JSON but not an executable specification

**Location:** `07:11-48`.

It omits:

- (q\in\mathbb N_{>0}) and (T_g>0);
- timestamp units and time origin;
- a reset-entry schema and message-reset semantics;
- the range (0\le k<q) in the machine-readable distance formula;
- the actual classifier, such as `CATCH iff delta <= w`, including boundary tolerance;
- numerical precision/rounding for (\varphi^{-2}); and
- a complete prospective multiplicity or holdout rule.

The algebraic period claim is correct for equally spaced, indistinguishable sites between reset epochs.

### 13. SW-1 is an integrity policy, not yet a statistical test

**Locations:** `13:40-71,154-175`.

No statistic, null distribution, threshold, multiplicity rule, or block/bootstrap method is specified. On the stated (h_6=0, Z_{000}) target, current reversal is an exact involution, so (P(W)=P(-W)) absent explicitly asymmetric conditioning. A “physical asymmetry” exception must name that conditioning. Local sign-dependent Metropolis acceptance is not itself a defect; compare the paired kernels under ((I,s)\mapsto(-I,-s)).

### 14. File 14's status categories are neither disjoint nor total

**Locations:** `14:50-76,83-139,158-175`.

`FR_PREFERRED` and `ESTIMATOR_DISCORDANT` can both be true; so can `FIT_INVALID` and diagnostic discordance. Yet the file requires exactly one label and gives no precedence. Diagnostics only “should” accompany the primary estimator, although Branch A requires concordance.

Use separate fields for model preference, fit validity, estimator concordance, and scale-gate result. Make diagnostics mandatory or define a `DIAGNOSTICS_MISSING` branch.

### 15. Some statistical machinery needs refinement

**Locations:** `04:962-979,1095-1126,1754-1780,2205-2217,2510-2570`.

- Importance-weight ESS (1/\sum\tilde w_a^2) ignores MCMC autocorrelation when compared directly with `N_raw`; use block/effective independent weights.
- Dropping covariance eigenmodes by raw eigenvalue relative to (\lambda_{\max}) is unit/scale sensitive unless variables are standardized or whitened.
- Ordinary BIC asymptotics are nonregular for selecting one versus two Gaussian-mixture components; calibrate the comparison by simulation/bootstrap or use a mixture-appropriate criterion.
- The displayed AICc correction is the usual independent-sample formula. With a correlated Gaussian data vector, justify the chosen effective (n) or calibrate model selection by bootstrap.
- The (L_{\min}) displacement denominator omits covariance between nested-window estimates, making apparent stability too easy when covariance is positive. Use the bootstrap distribution of the paired difference.

### 16. A complete empirical eight-state transition matrix is not always estimable

**Locations:** `03:393-400`; `04:3530-3546`.

If a state has no observed departures, its transition row is undefined. Report a count matrix, row denominators, intervals, and `NA` for unestimable rows. A descriptive row-normalized matrix does not establish Markov closure or stationarity.

### 17. Signed modulo-two behavior must be frozen for implementations

**Locations:** `02:1538-1542`; `13:161-164`.

Mathematically (-1\equiv1\pmod2), but programming-language remainder operators differ on negative inputs. Specify componentwise canonical residues in ({0,1}) and define subtraction in (\mathbb Z_2^3).

### 18. Smaller corrections

- `01:559-579` writes (I+M+\Gamma q=0\pmod2), mixing a 1-chain with a plaquette 2-chain. Use (\bar I+\partial M+\Gamma q=0), unless (M_\ell=(\partial M)_\ell) is explicitly redefined locally.
- `01:1387` says nonzero (\eta) does not identify the axis. Under its own table, (\eta=e_\alpha) identifies the toggled coordinate, though not sign/orientation or the microscopic operator.
- The “cocycles” are exact coboundaries: (c_q(m,n)=q_n-q_m) and (c_F(a,b)=Q(b)-Q(a)). This is mathematically fine, but periodic closure is substantive evidence only if side flux is measured independently rather than defined as (-\Delta Q).
- The poster's panel 2 draws an arrow (001\to010), which toggles two bits and is not one of the declared single-axis sector moves. Redraw it as the (3)-cube/Cayley graph or mark the arrows as non-transition layout guides.
- The fixed exponent (0.52742) is the central value (3-2(1.23629)); the source has uncertainty (0.00022). Propagate it or explicitly justify treating it as negligible relative to simulation uncertainty.
- `UPGRADE_CHECKSUMS.sha256` covers every listed packet payload and all matched, but it does not hash itself or the ZIP container. Say “binds the listed file contents,” not the complete archive byte stream, unless an externally anchored archive hash is supplied.
