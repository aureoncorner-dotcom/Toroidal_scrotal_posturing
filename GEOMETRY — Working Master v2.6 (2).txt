2. Core geometry (carried forward)
Declare a source domain (D), a retained map (\pi: D\to Q), and a witness (W: D\to Y). Work on attained labels (Q=\pi(D)).
Witness-relative equivalence
[
x\sim_W y \iff W(x)=W(y),\qquad Q_W \cong \operatorname{im} W.
]
Non-descent locus
[
N_W(\pi)={,q\in Q:\ \exists, x,y\in\pi^{-1}(q)\ \text{with}\ W(x)\ne W(y),}.
]
A point of (N_W(\pi)) is an attained label whose fiber contains a same-label pair that splits under (W); the pair is a collision witness, not the point of the locus. The coarsest exact refinement retaining both the label and the witness is the image of ((\pi,W)), with its projection back to (Q).
Exact descent of a witness through (\pi)
[
W = \overline W\circ\pi \iff \operatorname{Eq}(\pi)\subseteq\operatorname{Eq}(W).
]
Predictive closure (deterministic). For a forward-invariant domain and update (U:D\to D),
[
\pi(x)=\pi(y)\ \Longrightarrow\ \pi(Ux)=\pi(Uy).
]
For a stochastic kernel, require equal next-observation laws on every measurable target whenever labels agree. A fitted one-trace table does not establish the universal condition.
No-shape. Without extra hypotheses, any subset of (Q) can occur as (N_W(\pi)). A local collision does not determine global geometry. Openness, holonomy, and transport need their stated topological or smooth assumptions. Those assumptions are not supplied by the service layer.

3. The service stack
Write the conceptual stack as
[
X \xrightarrow{r} E \xrightarrow{\sigma} V \xrightarrow{q_{\mathrm{DS}}} Q_{\mathrm{DS}}.
]
Arrow        Name        Job
(r)        retention        Store execution as a typed episode record
(\sigma)        rendering        Declare what the interface presents
(q_{\mathrm{DS}})        service quotient        Identify episodes that serve the same object and answer
(X) is execution. Access to a specimen (E\in\mathcal E) does not imply access to (X). A stored stage label does not, by itself, prove the stage was displayed. Visibility is a separately retained observation (\operatorname{Vis}).
3.1 Eligible episodes
(\pi_{\mathrm{DS}}) is defined only on an eligible user-anchored response episode: there is a governing request, a served user object (O), and an answer-selection rule. If eligibility is UNKNOWN, the service projection is UNRESOLVED, not defaulted to “whatever the last assistant node said.”
3.2 Coordinate presentation
On the eligible domain,
[
E=(O,I,A),\qquad
A_i(O,I,A)=(O,\varnothing,A)\ \text{when (i) is the only interposition},\qquad
\pi_{\mathrm{DS}}(E)=(O,A).
]
More generally (A_i) deletes one identified separate stage record and leaves every other retained field untouched.
(O) — served user object, its anchor, and governing request.
(I) — ordered collection of separately represented interposition records (THOUGHTS, REASONING_RECAP, HIDDEN_META, CHECKING, tool-status bookkeeping, …).
(A) — answer payload under an explicit selection rule.
Source node identities, order, role, tool dependencies, provenance, and visibility stay attached to the underlying retained record. They are not reconstructed from the pair ((O,A)).
3.3 Two answer types
Symbol        Meaning        What evidence may use it for
(A_{\mathrm{sel}})        selected recorded text used by the ablation files        Exact string preservation
(A_{\mathrm{task}})        validated answer unit covering every span the governing request requires        Complete substantive service
E1–E4 establish claims about (A_{\mathrm{sel}}). Write (A=A_{\mathrm{task}}) only when claiming complete substantive direct service. A last-node label is not a completion proof. A pause, availability statement, or first non-status node is not an answer unit.
3.4 Service equivalence
[
E_1\sim_{\mathrm{DS}} E_2 \iff O(E_1)=O(E_2)\ \text{and}\ A(E_1)=A(E_2).
]
This is an equivalence relation. Its quotient is canonically identified with (\operatorname{im}\pi_{\mathrm{DS}}). Route-shape resemblance does not put different objects or different answers in one class.

4. The five service lemmas
These are the five additions the 9 September note proposed. They are stated here with domains.
Lemma S1 — Service factorization
On an eligible domain, there exists (q_{\mathrm{DS}}) with
[
\pi_{\mathrm{DS}} = q_{\mathrm{DS}}\circ\sigma
]
if and only if (\operatorname{Eq}(\sigma)\subseteq\operatorname{Eq}(\pi_{\mathrm{DS}})).
In practice. The rendered trace must preserve the object anchor and the selected answer. If a display omits the object, attach the anchor to the trace or the factorization fails for the object witness. If it truncates required answer content, the factorization fails for that content witness. The diagram is a typed contract, not a claim that every live interface already implements it.
Lemma S2 — Ablation is class-preserving
Let (A_i) delete one identified separate stage while preserving (O) and every other retained field. If
[
A(A_i E)=A(E)\qquad\text{and}\qquad O(A_i E)=O(E),
]
then (\pi_{\mathrm{DS}}(A_i E)=\pi_{\mathrm{DS}}(E)). The original and ablated records determine the same direct-service class.
If (i) is displayed as a separate service object, (i) is visibly nonessential for that specimen and answer witness. If display status is unverified, the established label is only nonessential in the retained presentation.
What this does not say. It does not say the stage was computationally idle. It does not say rerunning the hidden process without that stage would produce the same (A). Ablation acts on a representation.
Lemma S3 — Deletion operators commute on fixed identities
If stage identities are fixed and disjoint, and answer extraction does not depend on which of those records still remain, then
[
A_i^2=A_i,\qquad A_i A_j=A_j A_i.
]
If classification or selection changes after each deletion, combined invariance needs its own check. A family of single-stage results does not certify an adaptive deletion procedure.
Lemma S4 — Minimal representatives exist in finite admissible families
Let (R_E) be a nonempty finite family of admissible derived representatives within ([E]_{\mathrm{DS}}), with preserved provenance, task content, and necessary dependencies. Let
[
c_I(E')=|I_{\mathrm{vis}}(E')|,\qquad
M_E=\arg\min_{E'\in R_E\cap[E]_{\mathrm{DS}}} c_I(E').
]
The minimum is attained because this admissible family is finite and nonempty. It equals zero if and only if the family contains an admissible representative E' with I_vis(E') empty. This is zero visible interposition cost; retained audit records may still be present. In that case, the preferred served form is (O\to A).
That preference is the declared service objective. The quotient makes the objective precise. It does not impose the preference independently of the contract.
Lemma S5 — Deletion cost does not descend
Define (d_{\mathrm{DS}}(E)) as the minimum number of allowed unit-cost visible-stage deletions needed to reach a zero-interposition representative, or UNREACHABLE if none is admissible. When every visible stage is removable, (d_{\mathrm{DS}}(E)=|I_{\mathrm{vis}}(E)|).
Suppose (E\sim_{\mathrm{DS}} E^\ast) with (I_{\mathrm{vis}}(E^\ast)=\varnothing) and (I_{\mathrm{vis}}(E)\ne\varnothing). Any class-invariant distance on (Q_{\mathrm{DS}}) would give (d([E],[E^\ast])=0), while (d_{\mathrm{DS}}(E)\ne 0). Therefore (d_{\mathrm{DS}}) is a function of representatives, not a metric on (Q_{\mathrm{DS}}).
A separate retained-record cost (d_{\mathrm{ret}}) may count stored records without asserting UI visibility. Neither cost is elapsed time, compute saved, heat, or a causal distance between pipelines.

If deletion of a separately retained execution-stage coordinate preserves the served object and the declared answer witness exactly, the original and ablated records determine the same direct-service class. Where the ablated representation is admissible and renderable, that coordinate is unnecessary as a separate visible object for that specimen.
Internal computational necessity is not determined.

6. Answer fidelity and the continuation exception
Stage removal and answer selection are different maps.
A selected node can be source-text-exact and still be the wrong unit: a pause copied as the answer, a shorter later node that drops an image description, an adjudicative rider left inside (A), or two adjacent assistant nodes treated as one completion.
For an assistant-only continuation
[

]
stage-only ablation yields (O\to A_1\to A_2). Deleting (A_2) is a second operation. It requires a completion witness (C(O,A_1)=1) against the governing request, and whole-content preservation additionally requires
[
W_{\mathrm{req}}(O,,A_1|A_2)=W_{\mathrm{req}}(O,A_1).
]
A prefix can complete a task while differing from the recorded whole. Completion is not verbatim invariance. If (A_2) carries required new material, consolidate it into one answer unit or retain it. If completion is UNKNOWN, stage removal can proceed while continuation removal stays UNRESOLVED.

7. Correction binding is a vertical witness
Let (C_s) be an active correction prohibiting visible stage (s), and let (\operatorname{Elig}_s(t+1)) mark the next comparable response. Successful stage correction requires
[
\operatorname{Elig}s(t+1)=1\ \Longrightarrow\ s\notin\sigma(E{t+1}).
]
The prohibited object is behavioral: an independently emitted Checking stage is not the same as quoting the word in an audit. An assistant’s claim that the stage was needed does not establish the exception.
Theorem C — compliance does not descend through (\pi_{\mathrm{DS}}).
Take the same object and answer under the same active prohibition, once with stage (s) and once without. Then (\pi_{\mathrm{DS}}) agrees and the compliance witness differs. Hence stage compliance does not factor through (\pi_{\mathrm{DS}}). After the stage is erased, the served pair ((O,A)) cannot recover whether the historical response obeyed the correction.
Score historical compliance before projection. Score a repaired route on a new eligible observed response. Offline deletion cannot convert an original recurrence into a historical pass.
Audit refinement (use this when the claim is compliance, provenance, or visibility, not merely service):
[
\pi_{\mathrm{audit}}(E)=\bigl(\pi_{\mathrm{DS}}(E),\ K(E),\ \operatorname{Vis}(E),\ \operatorname{Prov}(E)\bigr),
]
where (K) retains the active correction, eligibility, answer-selection decision, and outcome. This is the image of ((\pi_{\mathrm{DS}},K,\operatorname{Vis},\operatorname{Prov})) — the ordinary coarsest exact refinement for those witnesses.
Answer-content corrections need their own predicate on (A). No-status success does not imply their success.

8. Presentation is not prediction
The service quotient asks whether a current answer can be presented without separate interposition. Predictive geometry asks whether a retained state determines its successor. These are different obligations.
Theorem P — current service labels do not give predictive closure.
There exist a deterministic response map (U_u), under a fixed next input (u), and eligible episodes (E_1,E_2) such that
[
\pi_{\mathrm{DS}}(E_1)=\pi_{\mathrm{DS}}(E_2)
\quad\text{and}\quad
\pi_{\mathrm{DS}}(U_u E_1)\ne\pi_{\mathrm{DS}}(U_u E_2).
]
Construction. Let both episodes serve the same ((O,A)) now. Attach a correction bit (k\in{0,1}) that is not part of ((O,A)). Define the next answer payload to equal (k). The current service labels agree; the next service labels differ.
This is a constructed obstruction, not a finding about a hidden runtime register. It is enough to forbid the inference “we served the same answer, therefore the service record is an autonomous state.”
The architecture may therefore minimize displayed stages while retaining a richer record for future control. Finite-horizon loss (\delta_h) and the coarsest autonomous refinement of a declared output (B) remain the right tools for that richer record. Zero visible interposition does not supersede the 39-screen coordinates (\theta), (z), and (\rho) relative to their own future-output witnesses.
If a service companion residual is wanted, type it separately:
[
\delta^V_{n+1}=\operatorname{Cmp}V(V_n,V{n+1}),\qquad
R^+{n+1}=(\delta^C{n+1},\delta^D_{n+1},\delta^K_{n+1},\delta^V_{n+1}).
]
(R^+) gains an autonomous law only if its own descent condition holds. Adding a clock repairs cross-time ambiguity. It does not repair a collision already present at one time.
