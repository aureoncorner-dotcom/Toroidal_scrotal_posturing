# Geometry Maximization v2.0 — Release report

6 September 2026

The compact core, exact reference simulator, offline explorer, Field Theory Update v0.3 and Simulation Protocol v0.5 are complete. All ten reference tests passed. Five included runs were regenerated byte-for-byte on this platform, and the extracted release was checked using the same verification entry point.

## Measured reference results

| Configuration | Departures | Exact slips | Ideal bins certified | Numerical bin mismatches | Mismatches on ideal-certified rows |
|---|---:|---:|---:|---:|---:|
| default_507 | 507 | 53 | 502 | 0 | 0 |
| warped_39 | 39 | 5 | 1 | 3 | 0 |
| exact_10000 | 10,000 | 1,034 | 10,000 | 0 | 0 |
| boundary | 39 | 4 | 38 | 0 | 0 |
| bin_boundary | 64 | 7 | 64 | 1 | 1 |

The default small-warp run gives 53 slips in 507 departures and certifies 502 ideal labels, with no numerical label mismatch. The larger warp gives three numerical mismatches and only one sufficient ideal certificate. Failure of a sufficient bound to certify a label does not imply that label is wrong.

The `boundary` run starts exactly at rho=tau, so its initial departure has no slip; its 39-departure count is four. The `bin_boundary` run starts at theta=19/39. At n=0 the exact bin is 19, while numerical inversion and re-transport give 18 with phase error about 5.55e-17 cycles. Identical initial data certify ideal G there; they do not eliminate floating-point roundoff. That mismatch remains in the release.

## Browser limits

The explorer was tested through a local-only HTTP preview. The browser URL security policy blocked the direct file-from-disk check; no bypass was attempted. The HTML embeds its data, script and styles and has no external runtime assets. Its direct offline-file execution was not tool-verified.

This app did not expose a completed browser download event. CSV preview and copying were verified, and every reference run includes a directly usable Python-generated `trace.csv`. No claim is made that browser saving or mobile layout was tested.

## Scientific status

This release turns the phase mathematics into an auditable working reference. It does not implement or run a toroidal production sampler, rerun historical empirical analyses, establish deconfinement, assign a physical central charge, or certify a proposed critical exponent. The updated field and simulation documents specify the missing model, kernel, stopping-rule, mixing and scale evidence. Those empirical requirements remain open.
